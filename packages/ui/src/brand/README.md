# Tokens de marca

`tokens.ts` define somente o contrato de integração da identidade visual.

Os valores oficiais foram transcritos do Brand Guideline v1.1 armazenado em `docs/brand/` e vinculados ao ativo oficial em `apps/web/public/brand/`.

Espaçamentos e border radius permanecem sem valor oficial porque não são especificados pelo guideline. Estados verde, âmbar e vermelho são tokens funcionais do BBOS, mantidos separados da paleta institucional.
